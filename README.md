# Parking Sensor System (Arduino)

This project is an Arduino-based parking sensor system using an ultrasonic sensor (HC-SR04).

## Features
- Real-time distance measurement
- Audio alerts using buzzer
- Visual alerts using LEDs

## Components
- Arduino Uno
- HC-SR04 Ultrasonic Sensor
- Buzzer
- LEDs

## How it works
The system sends ultrasonic waves and calculates the distance based on the time of flight. When an object gets closer, the buzzer alerts increase.

## Technologies
- C (Arduino)
- Embedded Systems
